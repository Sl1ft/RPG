# Подземелье смерти
## Что за игра?
Это консольная игра RPG-жанра, в которой вы герой, исследующий подземелье

## Как запустить?
Для запуска игры необходимо перейти в папку RPG, после чего запустить `python main.py`

## Команды в игре
- stats - Выводит статистику персонажа
- hunt - начинает бой со случайным монстром
- explore - позволяет исследовать подземелье
- use - позволяет использовать предмет из инвентаря
- save - сохраняет вашего персонажа
- inventory - выводит список предметов в вашем инвентаре
- help - выводит все действующие команды
- exit - завершает игру

## Как запускать тесты
Для начала необходимо установить библиотеку `pytest`
командой `pip install pytest`

Для запуска тестов необходимо зайти в терминал,
затем открыть папку RPG и выполнить `python -m pytest`

## Что реализовано
- ООП
- Абстрактные классы
- Свойства через `@property`
- `Enum`
- Сохранения в JSON файл
- Загрузка героя из сохранения
- Собственные исключения
- Лимиты сохранений
- Лимит инвентаря
- Тесты
